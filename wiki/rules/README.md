# wiki/rules/ — 학사 규정·제도

졸업요건, 교과과정, 교과목과 선수과목, 복수전공·부전공·연계전공, 장학금, 현장실습 같은 **규정과 제도**를 둔다.

- 파일 이름: `<slug>.md` (예: `graduation-requirements.md`, `double-major.md`)
- 형식: [templates/rule.md](../../templates/rule.md) — 한눈에 보기 표, 적용 대상별 상세, 예외, 관련 절차.
- 근거: 공식 자료(A)만.
- **적용 대상과 유효 기간을 반드시 적는다.** 입학 연도마다 규정이 다르면 파일을 쪼개지 말고 한 페이지 안에 "적용 대상: 2024학번 이후" 같은 섹션으로 나눈다.
- 연도가 다른 규정이 충돌하면 덮어쓰지 않고 양쪽 근거를 남긴다.
- 신청 방법·기한 같은 순서는 `wiki/procedures/`에 두고 링크한다.
