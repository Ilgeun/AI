# wiki/procedures/ — 절차

신청, 제출, 등록, 포기, 상담처럼 **순서가 있는 일**을 단계별로 둔다.

- 파일 이름: `<slug>.md` (예: `double-major-application.md`)
- 형식: [templates/procedure.md](../../templates/procedure.md) — 대상, 기한, 제출처·방법, 필요 서류, 담당 부서, 단계, 유의사항.
- 근거: 공식 자료(A)만.
- 기한은 매 학기 바뀔 수 있다. 유효 기간을 적고, 기한이 지나면 `status: stale`로 바꾼다.
- 왜 그런 절차가 있는지(규정)는 `wiki/rules/`에 두고 링크한다.
