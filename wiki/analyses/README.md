# wiki/analyses/ — 비교·종합 분석

여러 문서를 종합한 비교, 해석, 설명을 둔다 (예: 연도별 교과과정 비교). 위키 점검(Lint) 결과도 여기 남긴다.

- 파일 이름: `<slug>.md`, Lint 결과는 `wiki-health-YYYY-MM-DD.md`
- 형식: [templates/analysis.md](../../templates/analysis.md) — 질문·목적, 결론, 근거 표, 한계.
- 결론과 추론은 원본까지 거슬러 올라갈 수 있어야 한다. 추론은 `[!note] 추론` 상자로 표시한다.
- 질문에 대한 좋은 답 중 비교·종합 성격인 것을 Claude에게 저장해 달라고 하면 여기로 온다.
