# wiki/qa/ — 질문과 답변

자주 나오는 질문과 근거 있는 답을 쌓아 둔다. 같은 질문이 다시 오면 챗봇이 이 페이지를 바로 쓴다.

- 파일 이름: `<slug>.md` (예: `graduation-credits-2024.md`)
- 형식: [templates/qa.md](../../templates/qa.md) — **결론 → 근거 → 예외·주의사항 → 확인 필요 사항**.
- 답이 입학 연도 등에 따라 다르면 `applies_to`를 적는다.
- 질문에 대한 답을 Claude에게 저장해 달라고 하면 여기로 온다 (비교·종합은 `analyses/`).
- 근거가 된 규정·절차 페이지가 바뀌면 이 답도 함께 확인한다.
