# wiki/concepts/ — 학문 개념 (과목 공통)

여러 과목에서 함께 쓰는 **학문 개념** 페이지를 둔다 (예: 교착 상태, 시간 복잡도, 정규화). **개념 하나에 페이지 하나**만 두고, 과목·단원 페이지가 여기를 링크한다.

- **학사 규정·제도(졸업요건, 장학금, 교과과정)는 여기 두지 않는다** → `wiki/rules/`.
- 파일 이름: `<slug>.md`, 영문 kebab-case, **과목 이름을 붙이지 않는다** (`deadlock.md` ○, `os-deadlock.md` ×).
- 형식: [templates/concept.md](../../templates/concept.md) — 정의, 설명, 예시, 자주 헷갈리는 점, 과목별 쓰임, 관련 개념.
- 근거: **모든 과목의 공식 자료(A)만**. 후기(B)는 쓰지 않는다.
- 과목마다 정의나 표기가 다르면 "과목별 쓰임" 섹션에 과목별로 나눠 적는다.
