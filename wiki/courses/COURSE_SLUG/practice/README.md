# practice/ — 연습문제 세트

LLM이 출제 경향과 강의자료를 바탕으로 만든 연습문제다. **실제 기출이 아니다.**

- 파일 이름: `YYYY-MM-DD-<범위>.md` (예: `2026-11-20-units-05-08.md`)
- 형식: [templates/practice-set.md](../../../../templates/practice-set.md)
- 문제마다 붙는 것:
  - 유형, 난이도, 관련 단원·개념
  - **출제 근거** — 어느 학기 후기의 어떤 경향을 반영했는지 (B)
  - **정답·해설** — 공식 자료(A) 출처만. 접힌 상자라 클릭해야 보인다
- 공식 자료로 정답을 확정할 수 없는 문제는 만들지 않는다.
- 학생이 복기한 기출은 그대로 옮기지 않고 수치·조건을 바꿔 변형한다.
- 새 세트는 Claude에게 "N~M단원 연습문제 K개"처럼 요청하면 여기에 저장된다.
