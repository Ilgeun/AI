# wiki/courses/ — 과목별 공부 영역

과목마다 폴더 하나다. 폴더 이름은 `raw/courses/`의 과목 폴더 이름과 같다.

| 과목 | 상태 |
|---|---|
| [COURSE_SLUG/](COURSE_SLUG/) ({과목명}) | 프로토타입 진행 중 |

- 모든 과목 폴더는 같은 구조다. 자세한 내용은 각 과목 폴더의 README를 본다.
- 개념 설명은 과목 폴더에 두지 않고 [../concepts/](../concepts/)에 둔다.
- 졸업요건에서 이 과목이 필수인지, 선수과목이 무엇인지 같은 **학사 정보**는 `wiki/rules/`에 두고 과목 개요에서 링크한다.
