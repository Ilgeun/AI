## 페이지를 읽는 법

**출처 각주** — 모든 사실 문장 끝에 붙는다. 클릭하거나 마우스를 올리면 근거 파일과 위치가 보인다.

```
교착 상태는 네 가지 조건이 동시에 성립할 때 생긴다. ^[raw/courses/os/lectures/05-deadlock.pdf, p.8]
졸업 학점은 130학점이다. ^[raw/sources/graduation-regulation-2024/regulation.pdf, 제5조]
5단원 계산 문제가 매 학기 나왔다. ^[후기 2025-2, raw/courses/os/reviews/2025-2/r01.md]
```

- `raw/...`로 시작 → 공식 자료(A). 사실·정답·규정의 근거.
- `후기 YYYY-N, ...`로 시작 → 수강생 후기(B). **출제 경향일 뿐** 사실 근거가 아니다.

(위 예시의 숫자와 파일은 설명용이며 실제 내용이 아니다.)

**상자(callout)**

| 표시 | 뜻 |
|---|---|
| `[!note] 추론` | 여러 공식 자료를 종합한 LLM의 추론. 근거 출처가 붙어 있다 |
| `[!warning] 자료 간 불일치` | 공식 자료끼리 다름. 양쪽 출처를 나란히 적었다 |
| `[!question] 확인 필요` | 원본으로 확정할 수 없음. 담당 부서·공식 시스템 확인 필요 |
| `[!caution]` | 후기 기반 페이지라는 경고 (출제 경향) |

**frontmatter** — 페이지 맨 위 `---` 사이의 메타데이터.

| 필드 | 뜻 |
|---|---|
| `status` | `draft` 작성 중 / `active` 현재 유효 / `stale` 대체됐거나 기간 지남 |
| `sources` | 이 페이지가 인용한 raw 파일 |
| `applies_to`, `valid_from`, `valid_until` | 규정·절차의 적용 대상과 유효 기간 |

**링크** — `[[wiki/concepts/deadlock|교착 상태]]`처럼 저장소 루트 기준 전체 경로로 쓴다. Obsidian은 저장소 루트를 볼트로 열어야 링크가 맞는다.

## 검토할 때 볼 것

- 출처 없는 문장이 있는가
- 후기(`후기 ...`) 출처가 개념 설명, 정답, 규정에 쓰이지 않았는가
- 규정·절차에 적용 대상과 유효 기간이 있는가
- 이름·학번 같은 개인정보가 들어가지 않았는가

이상한 점은 Claude에게 "lint"를 요청하거나 직접 말한다.
