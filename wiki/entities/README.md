# wiki/entities/ — 조직·시설·시스템

학부 조직, 학과 사무실, 담당 부서, 실습실·연구실, 학생지원시스템 같은 **명사형 대상**을 둔다.

- 파일 이름: `<slug>.md` (예: `department-office.md`, `student-portal.md`)
- 형식: [templates/entity.md](../../templates/entity.md) — 역할, 위치, 운영 시간, 공식 연락 방법, 관련 절차.
- 근거: 공식 자료(A)만.
- 사람(교수·교직원)은 **공식 정보만** 적는다: 이름, 직위, 담당 업무, 공식 연락처. 개인 평가나 비공식 정보는 적지 않는다.
- 관련 절차·규정과 양방향으로 링크한다.
