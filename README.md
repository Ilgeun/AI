# PNU CSE Helper — 지식 저장소

부산대학교 정보컴퓨터공학부 전용 챗봇이 참고하는 **지식 위키**다.
LLM Wiki 패턴을 따른다: 사람이 원본 자료를 넣으면, LLM(Claude Code)이 읽고 정리해서 서로 링크된 마크다운 위키를 쌓고 유지한다.

> 이 파일은 함께 작업하는 **사람**을 위한 안내다. LLM이 따르는 정식 규칙은 [CLAUDE.md](CLAUDE.md)에 있다. 둘이 다르면 CLAUDE.md가 맞다.

## 현재 상태

| 영역 | 상태 |
|---|---|
| 과목 `COURSE_SLUG` ({과목명}) — 기말고사 공부 도우미 | 프로토타입 진행 중 |
| 학사 정보 — 교과과정, 졸업요건, 규정, 절차, 조직, 공지 | 구조만 있음 (기말 후 채울 예정) |

## 세 층

| 층 | 위치 | 누가 |
|---|---|---|
| 원본 자료 (raw) | [raw/](raw/) | 사람이 넣고, LLM은 읽기만 한다 |
| 위키 (wiki) | [wiki/](wiki/) | LLM이 쓰고, 사람은 검토한다 |
| 규칙 (schema) | [CLAUDE.md](CLAUDE.md) + [templates/](templates/) | 함께 정한다. Claude Code가 CLAUDE.md를 자동으로 읽는다 |

`wiki/`는 직접 고치지 않는다. 고칠 점이 있으면 Claude에게 말해서 고치게 한다 (그래야 출처·색인·로그가 같이 맞춰진다).
폴더마다 `README.md`가 있다. README는 사람용 안내문이며 위키 페이지나 자료로 취급하지 않는다.

## 자료 넣고 반영하기

1. 자료 종류에 맞는 폴더에 파일을 넣는다 ([raw/README.md](raw/README.md) 표 참고).
   - 학사 원본 (교과과정, 졸업요건, 공지 등) → `raw/sources/{source-id}/`
   - 과목 자료 → `raw/courses/<과목>/…`
2. 후기라면 **먼저 개인정보를 지우고**, 파일 이름을 `r01.md`처럼 짓는다 ([후기 안내](raw/courses/COURSE_SLUG/reviews/README.md)).
3. Claude Code에서 이렇게 말한다.
   ```
   ingest raw/courses/COURSE_SLUG/lectures/03-process.pdf
   ```
   ```
   이 원본을 ingest해줘: raw/sources/undergraduate-curriculum-2026/curriculum.pdf
   적용 학년과 졸업 요건을 중점적으로 정리해줘.
   ```
4. Claude가 핵심 요약을 보여 주고, 위키 페이지를 만들거나 고친 뒤 바뀐 파일 목록과 미해결 사항을 알려 준다.
5. `wiki/log.md`에 기록이 남는다.

한 번에 원본 하나씩 넣는 것이 기본이다. 여러 개를 한꺼번에 하려면 Claude에게 따로 말한다.

| 하고 싶은 것 | Claude에게 |
|---|---|
| 공부 질문 | "3단원 핵심 개념 정리해 줘" |
| 연습문제 | "5~8단원 기말 연습문제 10개 만들어 줘" |
| 학사 질문 | "2024학번 졸업요건 알려 줘" |
| 위키 점검 | "lint" |

## 꼭 지킬 규칙 (요약)

1. **사실·정답·규정은 공식 자료(A)만 근거로 한다.** 학사 원본, 강의자료, 강의계획서, 공식 기출·해설.
2. **수강생 후기(B)는 과목 출제 경향에만 쓴다.** 어느 학기 후기인지 항상 표시한다.
3. **개인정보(이름, 학번, 연락처 등)는 위키에 옮기지 않는다.**
4. **위키의 모든 사실 문장에는 출처가 붙는다.** 형식: `^[raw/…/파일.pdf, p.12]`
5. **규정과 절차에는 적용 대상과 유효 기간을 적는다.** 연도마다 다르기 때문이다.
6. **충돌하는 자료는 덮어쓰지 않고 양쪽 근거를 남긴다.**
7. **챗봇은 졸업 가능 여부 같은 개인 판단을 확정하지 않는다.**

## Obsidian으로 보기

- 저장소 **루트 폴더**를 Obsidian 볼트로 연다 (위키 링크가 `[[wiki/...]]` 루트 기준 전체 경로이기 때문).
- 그래프 뷰로 페이지 연결을, 인라인 각주 `^[...]`로 출처를 확인할 수 있다.
- 첨부 파일 폴더 경로를 `raw/assets/`로 설정한다 (설정 → 파일 및 링크).
- Dataview 플러그인을 쓰면 frontmatter(`status`, `valid_until` 등)로 표를 만들 수 있다.
