# raw/assets/ — 원본에 딸린 이미지·첨부

원본 자료에 딸린 이미지(웹 클리핑 이미지, 스캔본, 표 캡처 등)를 원본별로 둔다.

```
raw/assets/
├── {source-id}/        ← 학사 원본의 첨부
└── <과목>/             ← 과목 자료의 첨부
```

- Obsidian 설정 → 파일 및 링크 → 첨부 파일 폴더 경로를 `raw/assets/`로 하면 자동으로 이리로 저장된다.
- 이미지에 개인정보(얼굴, 이름, 메신저 프로필)가 있으면 넣지 않는다.
- 위키가 새로 만든 이미지·표·차트는 여기가 아니라 `wiki/assets/`에 둔다.
