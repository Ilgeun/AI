# raw/ — 원본 자료

챗봇 위키의 **근거가 되는 원본 자료**를 넣는 곳이다.

- 사람이 넣고, LLM은 **읽기만** 한다. LLM은 원본 파일을 수정·이동·삭제·이름 변경하지 않는다.
- 위키의 출처 표기는 이 폴더 안의 경로를 가리킨다. **한번 Ingest한 파일은 이름을 바꾸거나 옮기지 않는다.** 꼭 바꿔야 하면 Claude에게 말해서 위키 출처도 함께 고치게 한다.
- 이 폴더의 `README.md`와 `metadata.yaml`은 안내·정보 파일이며 원본 자료가 아니다.

## 어디에 넣나

| 자료 | 넣을 곳 | 등급 |
|---|---|---|
| 교과과정표, 졸업요건, 학사 규정, 학사일정, 학부 공지, 신청 안내 | `sources/{source-id}/` | A 공식 |
| 강의계획서, 공식 시험 범위 공지 | `courses/<과목>/syllabus/` | A 공식 |
| 강의 슬라이드, 노트, 교재 발췌 | `courses/<과목>/lectures/` | A 공식 |
| 교수·조교가 배포한 기출, 해설, 모의고사 | `courses/<과목>/exams-official/` | A 공식 |
| 수강생 후기, 학생이 복기한 시험 문제 | `courses/<과목>/reviews/<YYYY-N>/` | B 비공식 |
| 원본에 딸린 이미지·첨부 | `assets/{source-id 또는 과목}/` | — |

**등급은 폴더 위치로 정해진다.** A는 사실·정답·규정의 근거가 되고, B는 과목 출제 경향에만 쓰인다. 잘못된 폴더에 넣으면 위키 내용이 틀어진다. 애매하면 Claude에게 물어본다.

`sources/`에는 **공식 자료만** 넣는다. 선배 경험담 같은 비공식 학사 정보는 넣기 전에 Claude와 규칙을 먼저 정한다.

## 파일 형식

- PDF, PPTX, HWP, 마크다운, 텍스트, 이미지 모두 가능하다. 스캔본 PDF는 글자 인식이 안 될 수 있다.
- 새로 짓는 파일·폴더 이름은 영문 소문자, 숫자, `-`만 쓴다. 공식 원본의 원래 파일명은 그대로 둬도 된다.
- 파일 이름에 **개인정보(이름, 학번)를 넣지 않는다.**

## 새 과목 추가

`courses/<과목-slug>/` 아래에 `syllabus/`, `lectures/`, `exams-official/`, `reviews/`를 똑같이 만들고, Claude에게 "새 과목 <이름> 추가"라고 말한다.
