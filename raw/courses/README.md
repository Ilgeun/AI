# raw/courses/ — 과목별 원본 자료

과목마다 폴더 하나다. 폴더 이름(과목 slug)은 영문 kebab-case이고 `wiki/courses/`의 폴더 이름과 같다.

| 과목 | 상태 |
|---|---|
| [COURSE_SLUG/](COURSE_SLUG/) ({과목명}) | 프로토타입 진행 중 |

모든 과목 폴더는 같은 하위 구조(`syllabus/`, `lectures/`, `exams-official/`, `reviews/<YYYY-N>/`)를 쓴다. 하위 폴더별 넣는 법은 각 과목 폴더의 README를 본다.
