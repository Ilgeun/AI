# lectures/ — 강의자료 (A 공식)

- 넣는 것: 강의 슬라이드, 강의 노트, 판서 정리본(교수 제공), 교재 발췌.
- **학생이 만든 필기 정리는 넣지 않는다** (공식 자료가 아님). 넣고 싶다면 `reviews/` 쪽에 B로 둔다.
- 파일 이름: `NN-<주제>.pdf` — NN은 강의 순서 (예: `03-process-scheduling.pdf`). 위키 단원 번호와 맞춘다.
- 교재 발췌: `textbook-ch05.pdf`처럼 장 번호를 붙인다.
- 쪽수가 출처로 쓰인다. 슬라이드는 PDF 쪽 번호(`p.12`) 또는 슬라이드 번호(`slide 12`) 중 Ingest 때 정한 하나로 통일한다.
- 위키에서는 단원 페이지, 개념 페이지, 연습문제 정답·해설의 근거가 된다.
