# exams-official/ — 공식 기출·해설 (A 공식)

- 넣는 것: **교수·조교가 직접 배포한** 지난 시험지, 모범 답안, 해설, 모의고사, 연습문제와 풀이.
- 학생이 기억으로 복기한 문제는 여기 넣지 않는다 → `reviews/<YYYY-N>/`.
- 파일 이름: `YYYY-N-final.pdf`, `YYYY-N-final-solution.pdf`, `YYYY-N-midterm.pdf`, `practice-NN.pdf`.
- 위키에서는 정답·해설의 근거, 문제 형식(문항 수, 배점, 유형)의 공식 근거가 된다.
- 연습문제를 만들 때 기출을 그대로 옮기지 않고 변형해서 쓴다.
