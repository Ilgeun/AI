# reviews/ — 수강생 후기 (B 비공식)

지난 학기·작년 수강생의 시험 후기와 복기를 넣는다. **출제 경향(어느 단원·유형이 나왔는지, 난이도 체감)에만** 쓰이고, 개념 설명이나 정답의 근거로는 절대 쓰이지 않는다.

## 폴더와 파일 이름

```
reviews/
├── 2025-1/
│   ├── r01.md
│   └── r02.md
└── 2025-2/
    └── r01.md
```

- **반드시 학기 폴더**(`YYYY-1`, `YYYY-2`, `YYYY-summer`, `YYYY-winter`) 안에 넣는다. 위키는 이 폴더 이름으로 "몇 학기 후기"인지 표시한다.
- 파일 이름은 `r01.md`, `r02.md`처럼 번호만 쓴다. **이름·학번·닉네임을 파일 이름에 넣지 않는다** (출처 표기에 경로가 그대로 찍힌다).

## 넣기 전 개인정보 지우기 (체크리스트)

LLM도 위키에 옮기지 않지만, 원본에서 먼저 지우는 것이 가장 안전하다.

- [ ] 작성자 이름, 닉네임, 아이디
- [ ] 학번, 이메일, 전화번호, SNS 계정
- [ ] 후기에 나오는 다른 학생·조교 이름
- [ ] 개인 성적, 얼굴이 나온 사진
- [ ] 메신저 캡처라면 프로필 이름·사진

## 권장 형식

자유 형식도 되지만, 아래처럼 쓰면 경향 정리가 정확해진다.

```markdown
---
semester: 2025-2
exam: final            # final | midterm
source_type: 후기       # 후기 | 복기 | 설문
collected: 2026-11-20  # 수집한 날
---

## 시험 형식
- 문항 수, 시간, 오픈북 여부 등

## 나온 단원·주제
- 5단원 교착 상태 — 은행원 알고리즘 계산 문제
- ...

## 난이도·체감
- ...

## 기타 (공부 팁 등)
- ...
```
